# SafeProbing Project

## ✨ What’s Included

This repository provides:

* **pre-trained LoRA adapters**, available under: `lora_modules/`
* **Scripts to run inference and compute** the discriminator loss **($\mathcal{L}_{disc}$)** with:

  * the **vanilla model** (no safety-enhanced training)
  * the **safety-enhanced model** (via the provided LoRA adapter)
* **Safety evaluation** using **Llama-Guard-3-8B** (you need to download this model first)


## 🚀 Quick Start

### (1) As a baseline, you can skip safety-enhanced training and directly use vanilla model (Without Safety-Enhanced Training)

Run inference and compute **($\mathcal{L}_{disc}$)** directly with vanilla **Qwen2.5-7B-Instruct**. You can modify the prompt in the code.

```bash
python scripts/main.py --model_name qwen --model_path your_model_path --device 0
```


### (2) (Optional) Safety-Enhanced Model (Using the Provided Adapter)

Use the pre-trained adapter from `lora_modules/qwen`:

```bash
python scripts/main.py --model_name qwen --model_path your_model_path --adapter_path lora_modules/qwen --device 0
```


### (3) (Optional) 🔁 Re-Training the Adapter

If you’d like to re-train the safety-enhanced adapter yourself:

```bash
cd train
CUDA_VISIBLE_DEVICES=0 python train.py --model_path your_qwen_path --beta 0.5
```


### 🧪 Evaluation (Safety Judging)

We use **Llama-Guard-3-8B** to evaluate the harmfulness of model-generated responses.
Please download the model from: [https://huggingface.co/meta-llama/Llama-Guard-3-8B](https://huggingface.co/meta-llama/Llama-Guard-3-8B)

Example:

```bash
python scripts/judge.py --prompt your_prompt --response model_generated_response --device 0
```
